# 第一层表征：材料清单与评分定义

## 1. 目的、状态与固定规则

本页固定第一层（方法灵敏度下限）表征要用的材料、配对方式和评分定义，目的是在看到任何结果之前把“怎么算通过”写死。

状态：暂停（操作员，2026-10-05）。§8.8 的探查显示 clipping\_ratio 不能无条件解释为削波程度，正式表征在“回归比较的削波语义”确定前不得启动。已定的规则类决定（全覆盖、验证零越限、强制披露、只表征 0.99、按取值留出）保留；空对、变化对、适用域和数值表已在 §9 按第三页改写，操作员已于 2026-10-05 批准 §9；§2–§8 保留为原稿，§9 又经 §10 修订；冲突处依次以 §10、§9 为准。本页不授权生成材料、运行测量、写代码或落仓库；不含任何容差数值。

固定规则：

1. 材料清单、配对方式、分组、评分定义和 §7 的运行前决定，全部在第一次运行前批准并记录哈希。
2. 批准后改动任何一项，都要记录改动理由，并作废此前已看过的验证结果。
3. 验证材料在下限形式和取值冻结前不得运行，也不得查看。
4. 计划内的每一对都留在分母里：生成失败、测量无效、被拒绝比较都单独计数，不删除。
5. 全部材料是可控合成信号。结论只说明测量方法在受控条件下的行为，不是真实输入的质量认证。
6. 数值由确定性测量产生；LLM 不参与生成、挑选或解释数值。

## 2. 被测对象身份

表征对象是 `fb38314` 上工作台实际使用的削波测量，下表是我从源码核对到的定义；运行前须在当时基线上重新核对。

| 项 | 核对到的事实 | 对表征的含义 |
| --- | --- | --- |
| 指标定义 | `clipping_ratio` = 被判为削波的样本数 ÷ 分析范围样本数 | 天然以“样本数”为粒度；范围越短，一个样本的权重越大 |
| 机制一：满刻度 | 绝对值 ≥ `full_scale_threshold` 的连续样本段；阈值默认 0.99，属于用户可选的工具参数 | 阈值附近的样本会跳变 |
| 机制二：平顶 | 相邻样本差 ≤ 平顶容差的连续段，长度达到最小样本数，位于峰值附近，且是局部极值 | 叠加噪声或低位深量化可能让整段平顶不再被识别 |
| 两机制合并 | 取并集计数 | 同一个比例可能来自不同机制，需分机制报告 |
| 未进入参数快照的量 | 平顶容差、平顶最小样本数、满刻度最小连续样本数是 DSP 内部默认值 | 配置身份必须把这些默认值与代码摘要一并绑定，否则默认值改动后下限会静默失效 |
| 预处理 | 测量路径不做归一化、重采样、对齐 | 电平和时序扰动会直接进入测量值 |
| 测量版本 | `v0.3-regression-measurement-1` | 表征结果绑定该版本 |

由此得到两个设计后果，写在前面：

- **差值不一定小而连续。** 平顶机制在噪声或量化下可能整段失效，比例从某个值直接掉到 0。这类工况下可能不存在可批准的下限，正确结论是“该工况不适用”，而不是一个更大的数。
- **下限很可能要按工况分开。** 满刻度削波、次满刻度平顶、临界触顶、无削波的行为不同，评分按工况分别报告，不先合并。

## 3. 材料族清单

材料按“工况”分族，每族都是必须入测的人口，包括预期会让下限不成立的族。

| 族 | 内容 | 为什么必须有 | 现有生成器 |
| --- | --- | --- | --- |
| M1 无削波 | 幅度明显低于阈值的正弦 | 基线：两侧都应为 0，任何非零差值都是误报来源 | 有 |
| M2 临界触顶 | 峰值刚好在满刻度阈值上下的正弦 | 阈值附近的跳变性 | 有（调幅度） |
| M3 满刻度硬削波 | 削波电平不低于阈值 | 机制一的主工况 | 有 |
| M4 次满刻度平顶 | 削波电平低于阈值 | 只靠机制二识别，对噪声和量化最敏感 | 有 |
| M5 削波叠加谐波 | 谐波失真后再削波 | 非纯正弦波形下的平顶识别 | 有 |
| M6 有谐波无削波 | 高谐波含量但未触顶 | 反例：波形变形不应被当成削波 | 有 |
| M7 短平顶 | 基频相对采样率较高，每段平顶只有少数几个样本 | 平顶长度在最小样本数上下时的跳变 | 有（调频率） |
| M8 短分析范围 | 任一削波族配极短范围 | 分母小时一个样本的权重 | 有（调范围） |
| M9 双声道不同内容 | 左右声道削波程度不同 | 确认按声道分别成立，不被另一声道污染 | 需新增拼装 |
| M10 不适用输入 | 白噪声 | 必须落入“不适用/拒绝”，不得产生下限 | 有 |

每族的具体参数网格（频率、采样率、幅度、削波电平、时长）在 §7 列为运行前决定。网格要求：

- 频率同时包含与采样率成整数倍关系和不成整数倍关系的取值。
- 至少两个采样率。
- 削波程度覆盖轻、中、重。

“需新增”的材料属于实施工作，本页不授权。

## 4. 扰动与配对方式

表征的基本单位是“一对”：两份输入分别走工作台的真实测量路径，记录双侧值和差值。对分两类。

**空对（版本没变）：** 同一材料只施加一项与版本无关的扰动。空对的差值就是测量方法自身的变化。

| 扰动 | 做法 | 备注 |
| --- | --- | --- |
| P1 范围偏移 | 分析范围起止同时平移若干样本 | 工作台现规则要求两侧范围对应；这里模拟的是用户导出时起点有微小差异 |
| P2 范围长度 | 同一材料取不同长度的范围 | 用于判断下限是否随长度变化 |
| P3 起始相位 | 同一激励不同起始相位 | 削波正弦生成器目前没有相位参数，需新增或用范围偏移等效 |
| P4 位深 | 同一波形分别导出为 16 / 24 / 32 位整数 PCM | 较低位深的量化步长与平顶容差的关系是重点 |
| P5 微小电平差 | 整体增益有极小差异 | 模拟渲染链路的数值舍入差异；幅度取值在 §7 固定 |
| P6 叠加噪声 | 叠加固定种子的低电平噪声 | 噪声电平须跨过平顶容差：低于、接近、高于各至少一档 |
| P0 无扰动 | 字节完全相同的两份输入 | 健全性检查：差值必须为 0 |

**变化对（有意制造的已知变化）：** 同一材料仅改变削波程度，其余不变。用来回答“下限定在这里，会漏掉多大的真实变化”。变化幅度的档位在 §7 固定，必须包含极小的档。

约束：

- 每对只施加一项扰动。组合扰动留给验证阶段的指定子集，避免校准阶段就分不清来源。
- 随机性全部用记录在案的种子。
- 工具参数快照不同的两侧不构成对：现有规则已拒绝比较。本轮只表征默认满刻度阈值 0.99；日后要支持其他取值，每个取值是独立的配置身份，须重新表征。

## 5. 校准 / 验证划分

划分按“来源组”进行，不按单个文件或单对：同一来源组的所有对只能整体落在校准或验证一侧。

- **来源组的键：** 材料族 + 基频 + 采样率 + 削波程度档。同一组内的所有扰动变体、所有种子都属于该组。
- **校准侧用途：** 观察各工况下空对差值的分布，在预先列出的候选形式中选一种，并定出取值和适用条件。
- **验证侧用途：** 把冻结后的下限原样套上去，只计数，不调整。
- **验证侧必须包含：** 校准侧没有出现过的频率和削波程度取值、每个材料族至少一个组、指定的组合扰动子集、全部不适用输入。
- **划分方式：** 按参数取值留出（基频与削波程度两个维度，留出取值含内插与外推两类；采样率不留出），不在看过校准结果后挑选。名单在 §7 固定。
- **防泄漏：** 改文件名、改种子、改扰动幅度都不构成新的来源组。

## 6. 评分定义与分母

评分只做计数和分布报告，不输出“通过/优势”类结论；结论由审阅者对照 §7 预先固定的准则作出。

### 6.1 每对记录的量

- 双侧 `clipping_ratio`、双侧削波样本数、分析范围样本数。
- 差值，同时以“比例差”和“样本数差”两种单位记录。
- 双侧各自的机制标志（满刻度、平顶、是否判为削波机制）。
- 状态翻转：一侧判有削波、另一侧判无，或机制标志不同。
- 该对的终态：已测量 / 被拒绝比较 / 测量无效 / 生成失败，及原因码。
- 材料族、扰动、来源组、种子、配置身份、输入哈希。

### 6.2 分母

| 分母 | 定义 |
| --- | --- |
| 计划对数 | 清单中列出的全部对，运行前固定 |
| 已测量对数 | 双侧测量均有效且未被拒绝比较的对 |
| 适用对数 | 已测量对中，落在候选下限声明的适用条件内的对 |

覆盖率 = 适用对数 ÷ 计划对数，按材料族分别报告。适用条件收得越窄，覆盖率越低；两者必须一起看。空人口不报比率。

### 6.3 校准侧报告

- 按“材料族 × 扰动”逐格列出空对差值的完整分布，而非只给汇总数。
- 每格的状态翻转次数。有翻转的格单独标出。
- 差值与分析范围长度的关系，用来判断下限应以比例还是样本数表达。
- P0 健全性检查的结果；任何非零差值都意味着测量路径本身有问题，表征中止。

### 6.4 候选下限形式（预先列出，只能从中选）

| 候选 | 形式 | 何时合适 |
| --- | --- | --- |
| F1 | 固定的比例差 | 差值基本不随范围长度变化 |
| F2 | 固定的样本数差，折算成比例时随范围长度变化 | 差值主要来自边界和阈值处的少数样本 |
| F3 | 按工况分别取 F1 或 F2 | 各工况行为明显不同 |
| F0 | 该工况不设下限，标为不适用 | 存在状态翻转或差值不可界定 |

校准结果若显示四种都不合适，结论是“本轮无可批准下限”，不得临时发明第五种形式后继续。

### 6.5 验证侧计数

对冻结后的下限，在验证侧只报告以下计数及其分母，按材料族分别列出：

- **空对越限：** 适用空对中差值超过下限的对数。这是下限会导致的误报来源。
- **变化对未越限：** 适用变化对中差值未超过下限的对数，按变化幅度档分别列出。这是下限会掩盖的真实变化。同时报告最小可检出变化：从哪一档起全部变化对都越限。
- **适用条件外的对数：** 被排除在判定之外的对，逐类说明原因。
- **不适用输入：** 是否全部落入拒绝或不适用；任何一例产生了可判定结果都单独列出。
- **状态翻转：** 验证侧出现、而校准侧未见过的翻转。

- [ ] 校准 / 验证的划分规则：已定（操作员，2026-10-05），按参数取值留出。每个材料族预先指定若干基频和削波程度取值只出现在验证侧；留出取值既有落在校准取值之间的，也有落在校准范围之外的。采样率不留出，两侧都含全部采样率。不适用输入（M10）和指定的组合扰动子集只放验证侧。各侧的具体来源组名单随参数网格一并确定，仍待填。
- [x] 校准侧的覆盖准则：已定（操作员，2026-10-05）：全覆盖。下限不低于该工况下全部适用空对的最大差值，不加余量。盖不住的对只能用可观测的测量事实写入不适用条件，否则该工况整体走 F0。
- [x] 验证侧的接受准则：已定（操作员，2026-10-05）：硬条件只有一条，验证侧适用空对零越限，出现任何一对越限则该工况未通过。覆盖率不设数字门槛，强制披露覆盖率和被排除的对及原因。变化对未越限不作为通过条件，强制按变化幅度档报告被盖掉的对数，并给出最小可检出变化（从哪一档起全部越限）。适用范围与最小可检出变化是否还有用，由操作员审阅时判断。
- [ ] 产物存放位置与身份记录方式（材料哈希、代码摘要、配置身份、种子）：操作员 2026-10-05 决定暂缓，留到实施授权时对着当时基线确定。

退出条款：

- P0 健全性检查出现非零差值：中止，先作为测量缺陷处理。
- 某工况在校准侧出现状态翻转：该工况默认走 F0（不适用），除非适用条件能用可观测的测量事实把翻转排除在外。
- 验证侧出现空对越限：该工况保持 `descriptive_only`。不得事后缩小人口、调整下限或改准则后重算。
- 要再试一次：起新的一轮，用新的验证来源组；旧结果保留，不覆盖。
- 全部工况都未通过：这是合法结果。产品继续纯描述性，两层容差设计须据此重新评估。

表征通过也只产生第一层的候选数值与审阅包。启用产品判定仍需两层合成规则、新合同章节、测试 ID 和实施授权。

## 8. 候选数值表（待操作员审阅）

本节是材料取值的候选，不是容差；每个取值都对着源码常量选，理由写在表内。未运行任何测量，表中“预期”均为按公式推算。

### 8.1 选值所依据的常量

| 常量 | 值 | 来源 |
| --- | --- | --- |
| 满刻度阈值 | 0.99 | `ClippingInput` 默认值，本轮唯一配置 |
| 满刻度最小连续样本数 | 2 | `analyze_clipping` 默认值 |
| 平顶容差（相邻样本差，绝对值） | 1e-4 | `analyze_clipping` 默认值 |
| 平顶最小样本数 | 3 | `analyze_clipping` 默认值 |
| 16 位量化步长 | 约 3.05e-5 | 1 ÷ 32768，小于平顶容差 |
| 8 位量化步长 | 约 7.8e-3 | 1 ÷ 128，远大于平顶容差 |
| 基频搜索范围 | 50–1000 Hz | `FundamentalInput` 默认值 |
| WAV 时长上限 | 30 s | `WavLoadLimits` 默认值 |

### 8.2 共用轴

| 轴 | 校准侧 | 验证侧留出 | 理由 |
| --- | --- | --- | --- |
| 采样率 | 44100、48000 Hz | 不留出，两侧相同 | 两个最常见的采样率 |
| 基频 | 100、440、880 Hz | 220（内插）、50 与 997（外推） | 100 Hz 在 48 kHz 下每周期整数个样本，440 与 880 不是；50 是基频范围下沿，997 接近上沿且与两个采样率都不成整数关系 |
| 文件时长 | 2.0 s | 同左 | 生成器默认值，远低于 30 s 上限 |
| 分析范围长度 | 2.0、1.0、0.1、0.01 s | 0.5（内插）、0.02 与 0.005 s（外推） | 0.01 s 在 48 kHz 下只有 480 个样本，一个样本占比例约 0.2%；0.005 s 不足 100 Hz 的一个周期 |
| 随机种子 | 每格 5 个 | 另外 5 个，与校准不重复 | 只用于噪声扰动 |

分析范围长度是条件轴，不是配对扰动：工作台要求两侧范围等长，所以每个长度下把其余全部对各跑一遍。§4 表中的 P2 按此理解。

### 8.3 各材料族的取值

“削波深度”指削波电平与削波前峰值之比；比值越小削得越重。括号内是按纯正弦推算的削波比例。

| 族 | 校准侧取值 | 验证侧留出 | 理由 |
| --- | --- | --- | --- |
| M1 无削波 | 幅度 0.05、0.5、0.9 | 0.2（内插）、0.01（外推） | 平顶容差是绝对值，小幅度和低频正弦在峰值附近的相邻样本差可能小于 1e-4，见 §8.6 |
| M2 临界触顶 | 峰值 0.985、0.9895、0.99、0.9905、0.995 | 0.9899 与 0.9901（内插）、1.0（外推） | 在阈值 0.99 两侧各取近、远两档；1.0 是恰好满刻度 |
| M3 满刻度硬削波 | 削波电平 0.995；削波深度 0.999（约 3%）、0.99（约 9%）、0.9（约 29%）、0.7（约 51%） | 深度 0.95（内插）、0.9999 与 0.5（外推） | 电平高于阈值，两种机制同时生效；深度覆盖轻、中、重 |
| M4 次满刻度平顶 | 削波电平 0.5、0.9；深度同 M3 | 电平 0.7（内插）、0.98 与 0.1（外推）；深度同 M3 留出 | 只靠平顶机制；0.98 紧贴阈值下方 |

### 8.5 变化对的档位

变化对保持削波前波形不变，只降低新版一侧的削波电平，模拟“新版削得更重”。

| 类型 | 档位 | 理由 |
| --- | --- | --- |
| 削波加重 | 削波电平相对降低 1e-4、1e-3、1e-2、5e-2、1e-1 | 从接近平顶容差的极小变化到明显变化，跨三个数量级 |
| 新增削波 | 旧版为 M1（幅度 0.9），新版为同一波形按深度 0.9999、0.999、0.99、0.9 削波 | 用户最关心的情形：原来没有、现在有 |

变化对在校准侧与验证侧都生成，各自沿用该侧的来源组；只在验证侧用于报告最小可检出变化。

### 8.6 选值时发现的两个问题

- **干净正弦会被判出平顶（已用探查确认，见 §8.8）。** 平顶容差是绝对值 1e-4。正弦在峰值附近变化很慢：100 Hz、48 kHz、幅度 0.5 时，峰值两侧相邻样本差约 4e-5，小于容差，恰好可能形成 3 个样本的“平顶”。幅度越小、频率越低越容易发生。探查证实 M1 在这些格上的削波比例不是 0，而且会随相位跳变。这是我把 50 Hz、100 Hz 和小幅度放进网格的原因；它也可能是一个独立于本设计的测量问题，需要先确认。
- **削波指标没有“输入不适用”的判断。** 白噪声不属于周期测试信号，但削波测量对任何波形都会给出有效值；现有的不适用判断只在谐波测量一侧。因此 §3 中“M10 必须落入不适用”在现有代码下大概率不成立。第一层的适用条件需要一个可观测的事实来排除非周期输入，用哪个事实是新的开放问题。

### 8.7 规模估算

按上述网格粗算，校准侧约 150 个来源组，每组在 4 个范围长度下各约 30 对，合计在一万到两万对的量级；验证侧同量级。每对是两次对 2 秒以内音频的确定性测量，无模型调用。这是估算，精确对数在清单生成时确定并写入计划对数。

### 8.8 探查记录（2026-10-05，操作员授权的只读探查）

在 `fb38314` 上对生成器产生的干净正弦直接调用现有削波分析（默认参数，与工具层调用方式一致）。未改任何文件，脚本未保存进仓库。这是一次探查，不是表征：网格未按本页冻结，结果不得用于确定下限。

范围：采样率 44100 与 48000；频率 50、100、220、440、880、997 Hz；幅度 0.01、0.05、0.2、0.5、0.9；每格 4 个起始相位；2 秒。全部是没有任何削波的正弦。

结果：60 格中有 29 格的削波比例不为 0。

| 观察 | 实测例子 |
| --- | --- |
| 小幅度低频最严重 | 100 Hz、幅度 0.01、48 kHz：比例约 0.55 |
| 常见幅度也会发生 | 50 Hz、幅度 0.9、48 kHz：约 0.0125–0.0146；100 Hz、幅度 0.5：约 0.0125–0.0167 |
| 仅改起始相位就在有无之间跳变 | 100 Hz、幅度 0.9、48 kHz：相位 0 时 0.0125，其余三个相位为 0；440 Hz、幅度 0.05、44.1 kHz：相位 0 时为 0，其余约 0.0014 |
| 随采样率变化 | 100 Hz、幅度 0.5：48 kHz 下 0.0125–0.0167，44.1 kHz 下 0.0068–0.0136 |
| 高频大幅度不发生 | 440 Hz 及以上、幅度 0.2 及以上：全部为 0 |
| 机制标志始终为否 | 29 格全部是“检出平顶”为是、“削波机制”为否（峰值低于阈值） |

白噪声（每档 1 个种子）：RMS 0.1 时比例为 0；RMS 0.5 限幅到满刻度后比例约 0.004，机制标志为是。削波测量对噪声照常给出有效值，没有不适用判断。

对本设计的含义：

- `clipping_ratio` 单独不能代表“削波程度”：在低频或小幅度输入上，它有一个与削波无关、随相位和采样率变化的非零成分。
- 第一层在无削波工况下很可能走 F0，或者适用条件必须引用机制标志（例如要求两侧机制标志相同）。具体用哪个条件由表征决定，不在此预定。
- 是否改用只统计满刻度机制的比较指标，或修改平顶识别，都是对测量的变更，超出本切片；记为需要操作员决定的独立事项。
- 对现有单文件诊断的影响本次未验证。合同规定削波结论需要机制标志为是，而这 29 格的机制标志全为否，按该规则不会形成削波结论；但我没有端到端运行诊断路径来确认。

## 9. 按削波语义改写（2026-10-05，批准后发现问题，已由 §10 修订）

### 9.1 表征对象与产出

表征对象是满刻度样本数与满刻度状态；合并比例只作为辅助事实随每对记录，不参与任何下限。

该事实尚未实现。表征要等它的实施获授权并通过“判据与现有满刻度机制逐样本一致”的验收之后才能运行。

第一层产出两项，分别评分：

| 产出 | 回答的问题 | 用在哪里 |
| --- | --- | --- |
| 临界区边界 | 峰值离阈值多近时，满刻度状态会因版本无关的扰动而翻转 | 资格门：任一侧在临界区内则不判定 |
| 样本数差值下限 | 两侧都检出且都在临界区外时，版本没变样本数会差多少 | “是 → 是”的加重判定 |

### 9.2 候选形式（预先列出，只能从中选）

临界区边界：

| 候选 | 形式 | 何时合适 |
| --- | --- | --- |
| K1 | 峰值与阈值的距离不超过一个固定量，阈值两侧对称 | 翻转只集中在阈值附近且两侧行为相近 |
| K2 | 阈值上方与下方各一个固定量 | 两侧行为不对称 |
| K3 | 在 K1 或 K2 之外，再要求检出侧的样本数不低于一个固定个数 | 峰值距离不足以排除翻转，例如短范围或高频 |

样本数差值下限沿用 §6.4 的 F1–F3 与 F0，其中“比例差”指满刻度占比之差。

全覆盖准则对两项产出分别适用：临界区边界必须把校准侧全部状态翻转的空对圈在区内；样本数下限不低于区外全部空对的最大差值。

### 9.3 空对与变化对的含义

- **空对：** 版本没变时，记录双侧满刻度样本数、状态、峰值，以及状态是否翻转。验证侧的硬条件随之变为两条：临界区外的适用空对零状态翻转；两侧都检出的适用空对样本数差值零越限。两条都是“版本没变不得报回归”的不同形态，按已定的零越限准则推出，操作员已于 2026-10-05 确认。
- **起始变化对（否 → 是）：** 报告从哪一档起全部能在临界区外被判为起始，以及有多少对因为落在临界区内而拿不到判定。
- **加重变化对（是 → 是）：** 按变化幅度档报告被样本数下限盖掉的对数和最小可检出变化。
- **盲区变化对：** 确有削波但事实看不见的情形，单独列出、强制披露，不计入通过条件：次满刻度削波；每个峰只有 1 个样本过阈值的高频轻度削波。

### 9.6 改写时发现的问题

满刻度事实统计的是达到阈值的样本，不要求波形被削平（读代码得出，未实测）。峰值 0.995 的干净正弦会被计为“是”（独立审阅已实测确认：100 Hz 下约 6.3–6.7%，997 Hz 下约 3.7–4.5%）。

- 这不是新事实引入的：现有分析的满刻度机制和“削波机制”标志用的是同一判据。
- 它影响判定文案。“否 → 是”能说明的是输出开始达到满刻度阈值，这对“行为不变”的案例仍是有用的回归信号，但叫它“削波”说得比事实多。
- 表征因此新增 M11，并要求报告：同样的满刻度样本数下，削平与未削平的波形能否从现有输出区分（例如是否同时检出平顶）。这只是披露项，不预定结论。
- 文案已定（操作员，2026-10-05）：只陈述达到满刻度阈值的样本增减，不出现“削波”。

“恰好等于阈值”的档位（峰值 0.99、削波电平 0.99）行为取决于浮点舍入，只作为临界区内的表征点，不做特殊处理。

### 10.4 硬条件与披露项（替换 §9.3 的对应表述）

- 硬条件两条，只对批准域内、容忍范围内的验证侧空对适用：临界区外零状态翻转；两侧都检出时样本数差值零越限。
- 强制披露：域外的格、敏感度空对、盲区变化对、覆盖率、最小可检出变化。
- 固定样本数差的候选形式是否适用由表征决定。审阅实测的“只改相位样本数差 400”属于敏感度空对，不再直接否定该形式。
- M11 的披露项改为：从现有输出无法区分削平与未削平；去掉“是否同时检出平顶”，审阅实测未削波的低频正弦也会检出平顶。

### 10.5 运行前提与规模

表征须经完整工具路径（WAV 编解码与回归测量），不得只直接调用 DSP 函数。轴扩展后对数明显多于 §8.7 的估算，精确对数在清单生成时确定；全部仍是确定性测量，无模型调用。

### 10.6 复审后的补充（操作员 2026-10-05 同意）

- **位深。** 批准域只含 16、24、32 位整数 PCM。容忍范围内的位深空对为 32 对 24、32 对 16、24 对 16，校准与验证两侧都有。8 位改为域外披露项，不计入通过条件；§8.4 中“32 位对 8 位”不再作为验证侧的外推档。加载器拒绝浮点 WAV，无需为浮点定义步长。
- **P7 必须包含单向最坏情形。** 至少包括：全部样本向绝对值减小方向偏一个 16 位步长、全部向增大方向偏一步、截断对舍入、固定种子的随机偏一步。另设一项交叉核对：每个材料用“阈值减一步”和“阈值加一步”各计一次满刻度样本数，两者之差应不小于该材料所有容忍范围内空对的差值；不满足即说明扰动集不全，表征中止。复审实测供参考，不作下限依据：16/24 位下峰值离阈值超过约 1e-3 时无状态翻转；997 Hz 重削波的样本数差值不到 0.2%，边缘格可达约 7%；差值随峰数增长。
- **每对记录的量增加：** 双侧“过阈值但未计入的样本数”、双侧位深、每周期样本数、范围内周期数。
- **硬条件的临界区定义与第三页 §12.3 一致：** 状态为“否”的一侧若峰值达到或超过阈值，或有过阈值但未计入的样本，视为在临界区内。表征报告须分别给出应用这条规则之前与之后的状态翻转次数。
- **基频来源。** 表征材料的每周期样本数用生成参数计算；产品中它来自用户声明，系统不核对。报告须披露这一差别。

## 11. 第三次独立审阅后的更正（2026-10-05，操作员已同意）

与 §10 冲突处以本节为准。

- **删除 §10.6 中的一句参考说法。** “16/24 位下峰值离阈值超过约 1e-3 时无状态翻转”不成立。实测 997 Hz、48 kHz、16 位：峰值 0.9921（高出阈值 2.1e-3）舍入后计入 0 个，加一步后 32 个；峰值 0.99215 舍入后 64 个，减一步后 0 个。翻转点约在 0.99 ÷ cos(π/N)，N 为每周期样本数，N 越小离阈值越远。临界区的候选形式应能表达对 N 的依赖。
- **P7 的单向最坏情形以“全部样本同向偏一步”为准**，截断对舍入和随机偏一步都比它轻（第三页 §13）。
- **临界区对“是”“否”两侧都适用**，硬条件“临界区外零状态翻转”据此检验；固定最低要求见第三页 §13。
- §10.6 中“样本数差值不到 0.2%、边缘格约 7%”两个数字本次未复现，仍只作参考。

## 12. 实施计划审阅后的更正（2026-10-05，操作员已决定）

依据：实施计划 `docs/superpowers/plans/2026-10-05-s1-regression-layer1-characterization.md` 修订 1 的独立只读审阅。与 §11 冲突处以本节为准；其余落点见该计划 A、B、C 节。

- **容忍范围按叠加理解。** 合同 §23.4 的 “one quantization step … plus bit-depth conversion” 指两者可以同时出现。容忍范围内的空对新增“位深转换加一个较粗位深步长”一类（计划 B.3 的 P9）。审阅实测（完整工具路径）：100 Hz、48 kHz、幅度 0.989993、相位 π/480，16 位舍入峰值 0.98995972、计入 0，低于固定最低要求界线 0.99 − 2⁻¹⁵；同一波形 32 位舍入后整体远离零偏一个 16 位步长，计入 800。固定最低要求是否随之加宽，记为 OQ-022。
- **§9.5 起始变化对的校准深度 0.9999 改为 0.9995。** 0.9999 是 M3 的验证留出深度，原表会让校准侧看到验证组的同一段波形。验证侧保留 0.9999。
- **P3 只施加在起始相位为 0 的来源组上**，避免校准侧的相位叠加出验证留出相位。
- **P5 中逐样本差不超过一个 16 位步长的档（16 位下 ±1e-5、±3e-5）归入容忍范围内的空对**，与 §10.1 一致。

## 13. 实施计划第二轮审阅后的更正（2026-10-05，操作员已决定）
