# 回归比较的削波语义

## 1. 状态、起因与范围

本页定义回归比较在削波上到底比较什么：首期只对满刻度机制下判定，比较对象是一个新增的“满刻度样本数”事实，现有 `clipping_ratio` 降为辅助事实。

状态：操作员于 2026-10-05 批准后，同日的独立审阅发现实质问题（见 §11），操作员随后逐项作出修订决定，见 §12。当前有效的设计以 §12 为准；§12 已经独立复审（结论：入库与进入实施计划均为“修后可”），复审列出的六处修改已由操作员同意并写入；操作员已于 2026-10-05 批准 §12（仅设计内容）。复审后写入的六处修改未再经第三次独立审阅。§1–§10 保留为批准时的文本，仅做了文字性更正。本页不授权实施、合同改动、表征运行或落仓库；关于容差的准确表述见 §12.5。

起因：探查确认现有削波比例在没有削波的干净正弦上也会非零（60 格中 29 格），并随起始相位和采样率变化。它实际表示的是“满足满刻度或绝对平顶判据的样本比例”，不能无条件解释为削波程度。详见第二页 §8.8 与 OQ-020（已写入本地提交，未推送）。

范围：

- 在范围内：满刻度机制的比较事实、判定资格、状态转换的允许判定、现有比例的地位、对两层容差设计和第一层表征的调整。
- 不在范围内：次满刻度平顶削波的判定、真假平顶的区分、周期性自动检测、对平顶识别算法的任何修改。
- 不动：单文件诊断的检测器、阈值、v9.11 提示词与因果策略；冻结的 V0.2 §§1–64（含削波输出的字段）；§22 既有字段的含义。

本页的决定均由操作员于 2026-10-05 逐项确认，其中两项采纳了 Codex 的修订意见（资格门、独立重新渲染声明）。

## 2. 新的比较事实

新增一个比较专用的事实“满刻度样本数”，由新的确定性函数在回归测量路径中计算，不向冻结的削波输出添加字段。

| 项 | 定义 |
| --- | --- |
| 满刻度样本数 | 分析范围内、所选声道上，绝对值不低于满刻度阈值且至少连续 2 个样本的那些样本的个数 |
| 满刻度状态 | 样本数大于 0 为“是”，等于 0 为“否” |
| 满刻度占比 | 样本数 ÷ 分析范围样本数；仅用于展示，判定以样本数还是占比表达由第一层表征决定 |
| 判据来源 | 与现有削波分析的满刻度机制完全相同（阈值默认 0.99、最少连续 2 个样本），不引入新的检测逻辑 |
| 不包含 | 任何平顶识别结果；只有 1 个样本达到阈值的孤立峰 |
| 身份 | 绑定测量版本、阈值、最少连续样本数和代码摘要；与双侧输入身份和来源引用一并记录 |
| 层 | 计数在确定性 DSP/工具层完成；规则层只做比较；LLM 不生成、不修改该数值 |

已知边界，写入语义而非留作隐患：

- 高频轻度削波时每个峰可能只有 1 个样本过阈值，不被计入。报告须注明这一判据。
- 峰值贴近阈值时，状态会随相位、量化或微小电平差跳变。这个范围称为“临界区”，其边界由第一层表征给出，本页不定数值。
- 低于阈值处限幅的处理链（次满刻度削波）在这个事实里完全不可见。另有一条改写第二页时发现的边界（2026-10-05，读代码得出，未实测）：这个事实统计的是“达到阈值的样本”，不要求波形被削平。峰值高于 0.99 但并未削波的正弦同样会被计入，例如峰值 0.995 的干净正弦按公式约有 6% 的样本不低于 0.99（独立审阅已实测确认会被计入：100 Hz 下约 6.3–6.7%；997 Hz 下因孤立单样本被剔除，48 kHz 约 4.5%、44.1 kHz 约 3.7%）。因此“否 → 是”表示的是输出开始达到满刻度阈值，可能是削波，也可能只是电平升高。已定（操作员，2026-10-05）：判定与提示文案只陈述“达到满刻度阈值的样本”，不出现“削波”。

## 3. 判定资格门

只有下列条件全部成立，才允许对满刻度检查形成“发现回归”或“未发现回归”；任一不成立即为仅描述，并显示缺的是哪一条。

| 条件 | 性质 | 不成立时 |
| --- | --- | --- |
| 案例已明确声明属于首期批准的周期测试信号范围 | 用户声明，系统不验证；未声明不视为“是” | 未声明、未知或明确非周期：仅描述 |
| 现有条件声明允许比较 | 沿用 §22 现行阻断规则，不改 | 仅描述 |
| 测量配置有已批准的第一层 | 首期只有默认阈值 0.99 | 仅描述，显示“该测量配置无已批准的方法下限” |
| 两侧都不在临界区内 | 系统观测事实（双侧峰值与第一层给出的边界） | 仅描述，显示哪一侧在临界区 |
| 两侧都有第二层观测波动事实 | 系统观测事实，来自声明为独立重新渲染的重复 | 仅描述，显示还差哪一侧 |
| 观测与声明不矛盾 | 声明为确定性而重复间状态或样本数不一致即为矛盾 | 展示矛盾并阻断 |

起始回归（否 → 是）不因“变化很明显”而豁免任何一条。

周期测试信号资格是比较级的硬条件，不能用界面提示或产品文档代替。它不新增自动检测，也不与谐波测量是否有效挂钩。

## 4. 状态转换判定表

下表只在 §3 的资格条件全部成立时适用；状态先判，数值比较只在两侧都检出时进行。

| 旧版 → 新版 | 含义 | 允许的判定 | 必须展示 |
| --- | --- | --- | --- |
| 否 → 否 | 两版都没有达到满刻度阈值的样本 | 未发现回归 | 文案限定为“未发现达到满刻度阈值的样本增加”，不得写成“无削波”；辅助事实照常列出 |
| 否 → 是 | 起始：新版出现达到满刻度阈值的样本（可能是削波，也可能只是电平升高） | 发现回归 | 新版满刻度样本数、双侧峰值、重复运行中该状态是否稳定 |
| 是 → 是，新版更多 | 削波加重 | 增量同时超过两层时为发现回归，否则未发现回归 | 双侧样本数、差值、两层各自的值 |
| 是 → 否，或 是 → 是且新版更少 | 削波消失或减轻 | 未发现回归 | 同屏固定模板提示“达到满刻度阈值的样本减少”及双侧数值；只陈述事实，不解释原因 |

约束：

- 检查是有方向的：只有增加才可能构成回归。满刻度检查自身的判定与提示文案不出现“削波”（辅助事实区的固定提示和各侧单次测量事实不在此限）；表中“削波加重”“削波消失或减轻”只是本设计内部对情形的称呼，用户看到的是样本数的增减。不新增“改善”这一状态取值。
- 减少的提示与判定同屏显示，不得收在详情里。整体电平变化之类的原因不属于本检查能下的结论。
- “未发现回归”不等于无故障；两版均有削波时，双方的削波事实仍须保留展示。
- 满刻度检查的结论不进入单文件诊断的结构化结论，也不改变诊断的因果门。

## 5. 现有 `clipping_ratio` 的地位

现有合并比例保留在比较中，但永久为仅描述。

- 保留现有显示：双侧值和差值。原文称“已合入的行为和记录结构不变”，该说法不成立，见 §11 第 2 项。
- 新增条款：产品比较 profile 不得包含针对 `clipping_ratio` 的规则。这是对“哪些指标有资格建规则”的收窄，原文称“用新增条款表达，不改写 §22.3 原文”，已被 §12.8 取代：这是对合同含义的明示修订。
- 固定提示：“该比例含平顶识别结果，在低频或小幅度输入上可能包含非削波成分，不代表削波程度。”
- 版面：满刻度事实放在判定区，合并比例放在辅助事实区，两者不出现在同一行。
- 次满刻度削波首期不判定，这个比例是用户能看到的唯一线索，所以不移除。
- 现有的“削波机制”标志不用作判定或过滤条件：按代码，真的次满刻度削波与干净正弦的假平顶在该标志上都是“否”，无法区分。这一条来自读代码，次满刻度一侧未实测。

## 6. 对第二层的调整

主文档为第二层定的规则继续有效，对象从合并比例换成满刻度样本数，并有一处收紧。

- 观测波动按侧形成，记录每次重复的满刻度样本数和状态。
- 某一侧各次重复的状态不一致，即为观测到波动。
- 各次完全一致记为“观测波动 = 0”；0 波动不等于 0 下限，判定边界仍不低于第一层。
- 声明为 `unknown` 不因观测充足而自动解除；每案例 16 次提交上限不变。
- **收紧（取代主文档原结论）：** 只有用户明确声明“该文件来自一次独立重新渲染/重新运行”的重复提交，才计入第二层重复观测次数。声明为否、未知或未声明的，只记为重复提交，不计数。声明为独立且字节相同的可以计数，并照旧标注字节相同。

这个声明是用户声明，不是证明：工作台不执行用户程序，没有运行来源证据；记录中的运行标识由应用在每次上传时分配，标识的是一次测量。它能挡住无意的重复上传，挡不住不实声明。

## 11. 独立审阅发现（2026-10-05，待逐项决定）

操作员批准后，由一个未参与设计的子代理做了只读审阅。结论：可作为设计文档入库（需先做文字更正，已做）；暂不适合进入实施计划。以下五项是设计问题，每一项都可能改变范围，本页不当场定。

证据来源：标“实测”的是子代理在 `b4e79f4` 上直接调用现有 DSP 函数所得，未经完整工具路径，未跑测试，脚本未入库；标“读代码”的未实测。设计作者未逐条复跑。

- [ ] **1. 临界区的候选形式表达不了状态翻转的真实决定因素（实测）。** 翻转位置随频率、采样率和范围长度移动，不是固定的“峰值到 0.99 的距离”。未削波正弦只改起始相位：100 Hz 在峰值 0.9905 起全为“是”；440 Hz 在 0.9905 翻转；880 Hz 在 0.992（短范围下到 0.994）；997 Hz 在 0.9925–0.993；2 kHz 以上峰值到 1.0 都恒为“否”。反例：8 kHz、削波电平 0.995、削波前幅度 1.2，只改相位，样本数在 0 与 64000 之间翻转，峰值距离和最小样本数都排除不了。资格门里没有系统可观测的频率约束。待定：候选形式是否加入“每段过阈值的连续样本数”之类的可观测量，首期是否限定频率、采样率和范围长度下限。
- [ ] **2. 与已合入代码和合同的三处硬冲突（读代码）。** 其一，整体通过会恒为 False：必查项固定包含 `clipping_ratio` 与 `thd_percent`，且要求覆盖状态为已满足，而设计让前者永久仅描述、后者持续阻断。其二，声明阻断且有规则时代码返回“无法比较”，本页 §3 与主文档 §6 写成“仅描述”。其三，合同 §22.2 写明首期比较指标“only”两项，§22.3 不允许整数代替浮点，规则对象只有数值上下界；新增整数样本数事实与状态转换判定是对合同的修订，不是纯新增条款，应按 AGENTS.md 走 OQ 流程明示。待定：必查项怎么改、阻断状态取哪个、合同修订路径。
- [ ] **3. “不含任何容差数值”名不副实（读文档，部分实测）。** §4 表写“增量同时超过两层”，等于已把合成规则定为取最大值，而主文档和本页 §9 仍把它列为待批准。起始判定只要样本数大于 0 即判回归，容差实际是 0。在“全覆盖、不加余量”下，临界区宽度和样本数下限直接由第二页选入的最大扰动档决定，批准扰动网格实质上就是批准容差。实测佐证：100 Hz、削波电平 0.995、深度 0.99、2 s，只改相位，样本数在 10400 与 10800 之间，差值随峰数增长，固定样本数差的候选形式先验上不适用。待定：合成规则是撤回还是明示批准；扰动档位是否按“即容差”重新审阅。
- [ ] **4. 第二层在本切片内恒为 0（读文档与代码）。** 能拿到判定的案例必须声明确定性且重复完全一致，所以观测波动必为 0，“两层”退化为第一层加用户声明。把同一文件上传多次并声明独立渲染即可过门。版本未变仍可能报回归的路径包括：非确定性链加不实声明；第 1 项的高频相位翻转；代码不拒绝新旧版本号相同的比较；起点偏移只靠临界区兜底；最少重复次数若很小，轻微抖动链碰巧一致即可过门。待定：是否在主文档明示第二层在本切片不提供数值信息；是否拒绝相同版本号。
- [ ] **5. 判定落在哪条记录上未定义，转换表有遗漏（读文档与代码，部分实测）。** 记录不可变，重复是事后提交，初始比较永远是仅描述；现接口每次提交必须同时带两侧文件，“只重复一侧”如何发生、第 N 次重复自身是否出判定、16 次额度如何分配都没写。转换表未列“是 → 是且样本数相等”。“否”侧峰值高于阈值但不计数时（例如 997 Hz、峰值 0.991，2748 个过阈值样本全是单样本），“未发现达到阈值的样本增加”字面不真。幅度 0.99 存为 float32 后略大于阈值，“恰好等于阈值”的档位行为取决于舍入。第二页 M11 的披露项“是否同时检出平顶”区分不了削平与未削平：未削波的 50 Hz、峰值 0.995 正弦也检出平顶。

子代理同时复现了 OQ-020 的探查（60 格中 29 格非零，数值一致），并实测确认了 §5 中原来只是读代码的一条：次满刻度真削波（削波电平 0.5、0.9、0.98）的机制标志为否、满刻度样本数为 0，与干净正弦的假平顶在该标志上无法区分。

未能验证的范围：完整工具路径与 WAV 量化下的行为、位深/增益/噪声扰动下的翻转、单文件诊断不受影响的说法、`app/regression.py` 全文、既有测试对阻断状态的断言。

## 12. 修订后的设计（2026-10-05 第二轮，已复审，操作员已批准）

本节是当前有效的设计，自成一体；与 §1–§10 冲突处以本节为准。§11 的五项发现均由操作员在 2026-10-05 逐项决定，对应关系见 §12.10。

### 12.1 比较事实

满刻度样本数、满刻度状态、满刻度占比的定义同 §2，判据与现有满刻度机制相同。新测量同时记录两项辅助量，供资格判断使用：该侧峰值绝对值；过阈值但因不足连续 2 个而未计入的样本数。

已知边界不变：事实统计的是达到阈值的样本，不区分削平与未削平；次满刻度削波不可见。

### 12.2 记录与流程

满刻度检查用独立的新记录类型。现有比较记录的结构、必查项、整体通过逻辑和校验不动；产品 profile 继续为空，现有记录继续纯描述。

1. 首次提交是锚点比较。接口不变：每次提交同时带旧版与新版两个文件。
2. 重复提交同样带两个文件，用户对每一侧分别声明是否来自一次独立重新渲染（是 / 否 / 未知；缺省不视为“是”）。只想重复一侧时，另一侧传原文件并声明“否”，该侧不计数。
3. 每次有关联到锚点的提交被接受后，自动生成一条满刻度检查记录，不占提交额度。它引用锚点比较（标识与摘要）、用到的各次重复和第一层记录。资格不齐备时记录照样生成，状态为仅描述或无法比较，并列出全部不成立的条件；多个条件同时不成立时，“无法比较”优先于“仅描述”。被判定的是锚点比较的那一对。
4. 检查记录不可变。新记录指明它取代了哪一条；报告以最新一条为当前结论，旧的列为历史并标明已被取代。先前的“发现回归”可能因后来的重复不一致而被一条“无法比较”取代。
5. 检查记录的汇总只看满刻度检查自己，不继承现有的四项必查。报告必须同屏列出“THD 未覆盖、合并比例仅描述”，不得让满刻度结论看起来像整体通过。

### 12.3 判定资格

全部成立才允许形成“发现回归”或“未发现回归”。

| 条件 | 性质 | 不成立时 |
| --- | --- | --- |
| 现有条件声明允许比较 | 沿用 §22 现行阻断规则 | 无法比较（与已合入代码一致） |
| 声明为确定性，且每侧至少 1 次声明为独立的重复，该侧全部渲染的满刻度样本数与状态完全一致 | 声明 + 系统观测 | 重复不足：仅描述。重复间不一致：与声明矛盾，展示矛盾，无法比较 |
| 新旧版本号不同 | 声明 | 仅描述。现有代码不拒绝该提交，这一点不改 |
| 案例明确声明属于首期批准的周期测试信号范围 | 声明；缺省不视为“是” | 仅描述 |
| 已声明标称基频，且每周期样本数（采样率 ÷ 基频）与范围内周期数都不低于批准域下限 | 声明 + 系统观测；两个下限由第一层表征给出 | 仅描述，显示哪一项不在批准域 |
| 测量配置有已批准的第一层 | 首期只有默认阈值 0.99 | 仅描述 |
| 两侧都在临界区外 | 系统观测；边界由第一层表征给出 | 仅描述，显示哪一侧在区内 |

状态为“否”的一侧，若峰值达到或超过阈值，或存在过阈值但未计入的样本，按在临界区内处理。另加一条资格（复审后补充）：两侧文件都须为 16 位或以上的整数 PCM，否则仅描述；位深是系统直接读到的事实，加载器只接受 8、16、24、32 位整数、拒绝浮点格式（已读代码确认）。“该侧全部渲染一致”只看锚点和声明为独立的重复；声明为否或未知的只展示，不计数，也不构成矛盾。批准域依据用户声明的基频，系统不核对；声明与实际不符时下限不适用，报告须固定披露这一点。

起始（否 → 是）不因变化明显而豁免任何一条。这些声明都不可验证，能挡住无意的误用，挡不住不实声明。

### 12.4 第二层在本切片是一道门

重复运行的作用是检验“声明为确定性”是否属实，不提供数值。能拿到判定的案例观测波动必为 0。判定边界只由第一层给出；文档不再使用“同时超过两层”的说法。两层如何合成，留到修订 `observed_variable` 阻断的后续切片。

每侧最少 1 次独立重复是门的严格程度，不是容差。报告固定显示“基于每侧 N 次一致的渲染”。

### 12.5 第一层：容忍范围的定义

在本切片的资格前提下，真正版本没变的对输出逐字节相同，测量差值为 0。第一层要容忍的是新版本带来的、不构成回归的细微数值差异，这是一项明示作出的容差决定。

- **容忍：** 不超过两侧文件中较粗位深的一个量化步长的数值差异，以及位深转换本身。位深是系统能直接读到的事实。首期只对 16 位及以上成立：复审实测 8 位的步长约 0.008，舍入会把峰值 0.988 以上的信号推过阈值，与零越限准则必然冲突。容忍范围必须按单向最坏情形理解（全部样本同向偏一步，相当于截断对舍入），而不是随机偏一步：复审实测 997 Hz 下前者差 48 个样本、后者差 6 个。
- **不容忍：** 时间偏移、起始相位差、叠加噪声、超过一个量化步长的增益差。它们要么违反用户的对齐声明，要么本身就是行为变化，引起的样本数增加会被报告。
- **下限与临界区的来源：** 只用容忍范围内的空对来定，按全覆盖准则。
- **敏感度披露：** 不容忍的那些扰动仍然测，只用于报告它们会造成多大的读数变化、状态是否翻转，不进入下限。

关于采样相位：独立审阅实测到的随频率移动的状态翻转，来自两侧采样相位不同。在本节的容忍范围下这属于不被容忍的差异，只在两版时序确实不同时出现，并会被报告。批准域（每周期样本数、范围内周期数）仍保留，用途是避免判定建立在只差一两个样本的边缘状态上。翻转位置与每周期样本数的几何关系是推导所得，与审阅实测的 0.9905、0.992、0.9925 吻合，未单独验证，不作为产品规则。

“不含任何容差数值”的旧说法作废。准确的表述是：不含凭空设定的数值；容忍范围的定义是在这里明示作出的容差决定；批准域下限、临界区边界和样本数下限的具体值由表征给出。

### 12.6 判定表

状态先判；数值比较只在两侧都为“是”时进行。

| 旧版 → 新版 | 判定 | 必须展示 |
| --- | --- | --- |
| 否 → 否 | 未发现回归 | “未发现达到满刻度阈值的样本增加”；辅助事实照常列出 |
| 否 → 是 | 发现回归（按状态判，不设数值下限；保护来自批准域与临界区） | 新版样本数、双侧峰值、每侧渲染次数 |
| 是 → 是，新版增量超过第一层下限 | 发现回归 | 双侧样本数、差值、第一层下限 |
| 是 → 是，增量不超过下限，或样本数相同 | 未发现回归 | 同上 |
| 是 → 否，或 是 → 是且新版更少 | 未发现回归 | 同屏固定模板提示“达到满刻度阈值的样本减少”及双侧数值 |

文案约束同 §4：满刻度检查自身的判定与提示不出现“削波”。判为“发现回归”时同屏固定提示：差异可能来自导出设置（位深、抖动、增益、起点），不一定来自版本。如果表征显示起始需要最小样本数，走第二页已列出的候选形式，并作为表征结论另行批准。

### 12.7 现有 `clipping_ratio`

保留显示，永久仅描述，产品 profile 不得含针对它的规则，附固定提示，放在辅助事实区。由于满刻度检查有自己的记录和汇总，这一条不会触发现有记录“整体通过恒为 False”的问题：现有记录在产品路径上没有 profile，整体通过为空。

### 12.8 合同路径

这是对合同含义的明示修订，不是纯新增条款。

- 新章节写明对 §22.2“only”的澄清：那句话约束的是现有比较记录里的指标；满刻度检查记录是另一个对象，其样本数为整数，不受 §22.3 浮点规则对象的约束。
- 需要一条新的决策记录和一组新的测试 ID，并更新 OQ-020 中“不改代码或合同”的表述。
- 冻结的 V0.2 §§1–64 不动；单文件诊断的检测器、阈值、提示词与因果策略不动。

### 12.9 范围后果

本切片做完后，能拿到判定的案例须同时满足：声明为周期测试信号并声明基频、在批准域内、声明为确定性且每侧至少两次渲染完全一致、新旧版本号不同、默认阈值、两侧在临界区外。次满刻度削波、有抖动的链、高频或极短范围、非默认阈值都只有描述。新版只要有超过一个量化步长的差异并导致样本数增加，就会被报告。8 位文件只有描述。另外，重复之间要求完全一致，而版本之间容忍一个量化步长：本身有一步以内不确定性的链会被判为与确定性声明矛盾，拿不到判定。

## 13. 第三次独立审阅后的更正（2026-10-05，操作员已同意）

一个未参与设计的子代理对 §12 和合同修订草稿做了只读审阅。以下更正与 §12 冲突处以本节为准。实测均为直接调用 DSP 函数，未经完整工具路径，未跑测试。

- **临界区对两侧都适用，并设固定最低要求。** §12.3 只规定了“否”侧峰值达到阈值时视为区内，这挡不住被容忍的一步差异。实测 100 Hz、48 kHz、2 s、幅度 0.990011、16 位：基线计入 0 个、峰值 0.9899902，按原规则在区外；同一信号整体加一个量化步长后计入 800 个，会被判为发现回归。更正：表征给出的临界区对“是”“否”两侧都适用，必须包含任何会被容忍差异推过状态边界的信号；与表征无关的固定最低要求是，“否”侧峰值不低于“阈值减去较粗位深一个量化步长”即视为区内。对“否”侧而言，“峰值达到阈值”与“存在过阈值但未计入的样本”是同一条件。
- **重复提交计数的前提。** 重复提交须与锚点使用相同的测量选择、分析范围、采样率、通道和两个版本号，且自身条件声明不阻断，才计入；否则只展示并写明原因。资格条件中读取声明和版本的各项一律读锚点那次提交；两项独立渲染声明只在重复提交上读取。
- **计算所在的层。** 满刻度计数是 DSP 层的函数，由工具层在测量当时调用，结果与测量包并列保存；测量包及其摘要不变。测量结束后样本不保留，因此样本数在校验时无法重算，只受摘要保护；状态、峰值和样本总数可与测量包交叉核对。
- **更正 §11 第 1 项的一句话。** “2 kHz 以上峰值到 1.0 都恒为否”在 48 kHz 下不成立：峰值 0.9986 和 1.0 时状态取决于相位。该说法只在 44.1 kHz 下复现。
- **更正 §12.5 的一句话。** “单向偏一步相当于截断对舍入”说轻了。实测 997 Hz、峰值 0.995、16 位：舍入 4272，全部加一步 4320（差 48），截断 4256（差 16），随机偏一步 4286（差 14，而非 6）。容忍范围按“全部样本同向偏一步”理解。
- **对合同的影响比 §12.8 写的大。** 除 §22.2 的 “only” 外，还有：禁止为 `clipping_ratio` 建规则后，现有比较记录的整体通过在产品路径上永远不可能为真；§22 与 D042 “未授权产品容差”的表述被部分取代（定了容忍什么，未定任何数值）；提交指纹、上传对象和案例快照的形状会扩展。详见合同修订草稿 A 节。
